# **App Name**: CSS Prep Hub

## Core Features:

- Past Paper Viewer: Displays past papers with ideal answers and marking schemes, filterable by year, subject, and category.
- Subject-Wise Practice: Allows users to practice subject-wise questions, with questions filterable by subject, topic, and difficulty level.
- AI Answer Check: AI-powered answer checking using Google Gemini. Users can input their answer via text editor or image upload (OCR). Returns a detailed score breakdown with strengths, weaknesses, and improvement tips, functioning as an intelligent tool.
- Quizzes: Enables users to take quizzes on specific subjects, receive instant scores, and view correct/incorrect answers after submission.
- Interview Prep: Provides a Q&A bank for interview preparation, categorized into General Knowledge, Current Affairs, and Personality questions.
- Psychological Tests: Offers psychological tests simulations including personality-based MCQs and sentence completion tests.
- Progress Tracker: Visualizes progress and improvements with charts for quiz scores and AI-marked answer scores over time, highlighting strong and weak subjects.

## Style Guidelines:

- Primary color: #3498db (RGB) - A vibrant blue to convey trust and knowledge, reflecting the app's educational focus.
- Background color: #ecf0f1 (RGB) - A light gray to ensure readability and minimize distractions.
- Accent color: #e74c3c (RGB) - A vivid red to draw attention to important elements and calls to action.
- Body and headline font: 'Inter' (sans-serif) for a modern, clean, and readable user interface.
- Use a consistent set of icons from 'Lucide' to maintain a clean and modern design aesthetic. Icons should be simple, recognizable, and aligned with the app's functions.
- Dashboard uses a card-based layout to provide a clear, organized, and user-friendly experience. Ensure mobile-first responsiveness for accessibility across devices.
- Subtle transitions and animations for a polished user experience. Use micro-interactions for button presses and loading sequences to provide feedback without overwhelming the user.
